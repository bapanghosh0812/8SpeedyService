# speedy_core

Official shared core library for the **8SpeedyService** Customer (`in.speedyservice8.customer`) and Partner (`in.speedyservice8.partner`) applications.

## Modules
- `src/theme.dart`: Material 3 color system, typography, and vector `SpeedyLogoMark` / `SpeedyBrandHeader`.
- `src/models.dart`: Immutable domain models (`Catalog`, `Booking`, `JobOffer`, `PartnerProfile`, `EarningsSummary`).
- `src/api_client.dart`: REST + Socket.IO client for the 8SpeedyService dispatch backend.
- `src/session.dart`: Phone OTP authentication & session state controller.
