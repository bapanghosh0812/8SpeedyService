# 8SpeedyService

On-demand roadside mechanic dispatch platform for India.

## Packages & Applications

- `apps/customer` (`in.speedyservice8.customer`) — Customer mobile client (Flutter / Material 3).
- `apps/partner` (`in.speedyservice8.partner`) — Partner mechanic duty & dispatch console (Flutter / Material 3).
- `packages/speedy_core` — Shared domain models, theme, REST client, and Socket.IO client.
- `backend` — Fastify + PostgreSQL 16 + Socket.IO + Firebase Auth dispatch and ledger service.

## Development

```bash
cd backend
npm install
npm run typecheck
npm test
```
