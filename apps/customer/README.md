# 8SpeedyService Customer App (`in.speedyservice8.customer`)

Official **8SpeedyService** Customer application built with Flutter 3 (Material 3). Provides 3-tap roadside mechanic booking (`Pick Issue` → `Pick Vehicle` → `Book Mechanic`), real-time GPS tracking, 4-digit Start OTP verification, extra part charge approval, and mechanic ratings.
